# Lab Manager backend

FastAPI service backed by Postgres, managed with uv. The API is served under `/api`, with docs at `/api/docs`.

## Prerequisites

- [uv](https://docs.astral.sh/uv/), which must be on PATH because the pre-commit hooks call it
- Docker

## First-time setup

The compose `db` needs `src/.env`, so copy `src/.env.example` to `src/.env` first. Its credentials match `backend/.env.example`. Then run from `src/backend`:

```bash
uv sync
cp .env.example .env
docker compose -f ../docker-compose.yml up -d db
uv run alembic upgrade head
uv run pre-commit install
```

## Running the API

```bash
uv run uvicorn app.main:app --reload --port 5000
```

The full stack, including the frontend on `http://localhost/`, starts with `docker compose up --build -d` from `src`.

## Tests

The tests run against the database in `.env`:

```bash
uv run pytest
```

## Migrations

```bash
uv run alembic revision --autogenerate -m "describe the change"
uv run alembic upgrade head
```

Review the generated file before committing it.

## Creating an admin

```bash
uv run python -m app.cli create-admin --email you@uta.edu --name "Your Name"
```

Against the running stack, use `docker compose exec backend uv run --no-sync python -m app.cli create-admin ...` from `src`.

## OpenAPI contract

`openapi.json` is generated by `uv run python -m app.cli export-openapi`, which the pre-commit hook runs on every change under `app/`. The hook needs uv on PATH and `src/backend/.env` present, since the export loads the app settings. Never edit it by hand.
